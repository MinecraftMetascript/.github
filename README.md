# .github

Organization-wide files for [MinecraftMetascript](https://github.com/MinecraftMetascript).

- [`profile/README.md`](profile/README.md) is the landing page shown on the organization's GitHub page.
- [`profile/assets/`](profile/assets) holds the brand marks it uses, plus images for GitHub settings:

| File | Use |
| --- | --- |
| `logo-light.svg`, `logo-dark.svg` | Full logo (mark and "MMS Metascript" wordmark) for light and dark backgrounds |
| `mark-light.svg`, `mark-dark.svg` | Mark alone, for light and dark backgrounds |
| `avatar.svg`, `avatar.png` | Mark on a blue square (512px PNG). Upload as the organization avatar under **Settings → Profile** |
| `social-preview.png` | 1280×640 card. Upload as the social preview of `mms` under **Settings → General → Social preview** |

The SVG sources and the script that builds them live in [`mms/branding`](https://github.com/MinecraftMetascript/mms/tree/main/branding). Copy them here again when the logo changes.
